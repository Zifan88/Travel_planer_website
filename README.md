# Travel Planner Website

A modern and responsive travel planning website designed to help users explore beautiful destinations and create their own travel plans.

## 🌐 Live Demo

[Visit Travel Planner Website](https://zifan88.github.io/Travel_planer_website/)

## ✨ Features

- Explore popular travel destinations
- Beautiful destination cards with images
- Interactive travel planning interface
- Create a personalized travel plan
- Travel date selection
- Destination selection
- Responsive and user-friendly design
- Clean and modern interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 📍 Destinations

The website currently includes destinations such as:

- Paris
- Bali
- Santorini
- Swiss Alps
- Tokyo
